Schema

The full schema of the database is provided below.

For each section, a short description is followed by the schema data.

The schema must be used when generating SPARQL queries.

The lpg schema uses the concept of a GeoObject.

A GeoObject is a spatial concept and can be considered a formalized extension of a traditional GIS feature.

A GeoObjectType contains the metadata that defines a concrete GeoObject.

============
Joining Data
============

The lpgvs:Project type is conceptually equivalent to cwbi:Remis_Project.

The lpgvs:Project object has geometry and location data.

The cwbi:Remis_Project object has REMIS program, budget, and costing relationships.

Both objects use the same project code.

Example:

?project rdf:type lpgvs:Project ;
lpgs:GeoObject-code "30000667" .

?remisProject rdf:type cwbi:Remis_Project ;
skos:altLabel "30000667" .

To find projects associated with a program:

1. Find the cwbi:Program using its skos:altLabel.
2. Navigate from cwbi:Remis_Project to cwbi:Program using cwbi:Program.
3. Read the REMIS project code from skos:altLabel.
4. Join the REMIS project code to lpgs:GeoObject-code on lpgvs:Project.
5. Return the lpgvs:Project as ?uri.
6. Return "Project" as ?type.
7. Return the shared project code as ?code.
8. Return the LPG project label and geometry.
9. Return applicable project financial attributes as additional variables.

When returning project or program information intended for mapping, return the LPG Project objects and their geometries.

===
How much was spent on a program with code 000510?
What is the budget for a program with code 000510?
How much budget is remaining on program 000510?
===

Budgetary information is stored at the program level.

Costing data is stored at the project level.

Project costs can be aggregated to the program level and compared with the program budget.

The lowest-level returned objects should still be the LPG Project objects.

PREFIX apex: <http://dime.usace.mil/data/dataset#>
PREFIX cwbi: <http://dime.usace.mil/ontologies/cwbi-concept#>
PREFIX pm: <http://data.sec.usace.army.mil/ontologies/pm#>
PREFIX pmcommon: <http://data.sec.usace.army.mil/common/ont/pm#>
PREFIX sdsfie: <http://dime.usace.org/taxonomy/sdsfie/>
PREFIX lpgs: <https://localhost:4200/lpg/rdfs#>
PREFIX lpg: <https://localhost:4200/lpg#>
PREFIX lpgv: <https://localhost:4200/lpg/graph_801104/0#>
PREFIX lpgvs: <https://localhost:4200/lpg/graph_801104/0/rdfs#>
PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX dct: <http://purl.org/dc/terms/>
PREFIX geo: <http://www.opengis.net/ont/geosparql#>
PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>

SELECT DISTINCT
?uri
?type
?code
?label
?wkt
?projectCost
?programBudget
?projectCount
?totalCost
?averageCost
?minimumCost
?maximumCost
?remainingBudget
WHERE {
GRAPH <http://dime.usace.mil/data/dataset#REMIS_PROJECTS> {
?program rdf:type cwbi:Program ;
skos:altLabel "000510" ;
cwbi:ProgramBudget ?programBudget .

?remisProject rdf:type cwbi:Remis_Project ;
              cwbi:Program ?program ;
              skos:altLabel ?code .

OPTIONAL {
  ?remisProject cwbi:ProjectCost ?projectCost .
}

}

GRAPH <https://localhost:4200/lpg/graph_801104/0#> {
?uri rdf:type lpgvs:Project ;
lpgs:GeoObject-code ?code ;
rdfs:label ?label .

BIND("Project" AS ?type)

OPTIONAL {
  ?uri geo:hasGeometry ?geometry .
  ?geometry geo:asWKT ?wkt .
}

}

{
SELECT
(COUNT(DISTINCT ?aggregateProject) AS ?projectCount)
(SUM(xsd:decimal(?aggregateCost)) AS ?totalCost)
(AVG(xsd:decimal(?aggregateCost)) AS ?averageCost)
(MIN(xsd:decimal(?aggregateCost)) AS ?minimumCost)
(MAX(xsd:decimal(?aggregateCost)) AS ?maximumCost)
WHERE {
GRAPH <http://dime.usace.mil/data/dataset#REMIS_PROJECTS> {
?aggregateProgram rdf:type cwbi:Program ;
skos:altLabel "000510" .


    ?aggregateProject rdf:type cwbi:Remis_Project ;
                      cwbi:Program ?aggregateProgram ;
                      cwbi:ProjectCost ?aggregateCost .
  }
}


}

BIND(
xsd:decimal(?programBudget) - COALESCE(?totalCost, 0)
AS ?remainingBudget
)
}
ORDER BY DESC(xsd:decimal(?projectCost))
LIMIT 100
